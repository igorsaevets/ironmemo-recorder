Privacy Policy — IronMemo Audio Recorder

Effective date: 9 September 2026 · Back to home

IronMemo Audio Recorder ("the extension") is a Chrome extension that records microphone and browser tab audio on the user's own device. This policy explains exactly what data the extension handles and what it does not do.

1. Data the extension handles

The extension handles three categories of data:

  • Microphone audio — captured only during a recording that the user has explicitly started. Classified by the Chrome Web Store as Personal communications.
  • Browser tab audio — captured only during a recording that the user has explicitly started, and only from the specific tab the user chose. Classified by the Chrome Web Store as Website content.
  • Extension settings and consent state — small key/value pairs (recording preferences, consent version, timestamps) stored in chrome.storage.local. Classified as Website content.

The extension does not handle any of the following: web browsing history, form input, passwords, personally identifying information beyond what the user chooses to speak into the microphone, location, health data, financial information, authentication credentials, or personal communications outside of the user-initiated recording.

2. Where the data is stored

All recorded audio and settings stay on the user's device. Recorded audio is written to the browser's Origin Private File System (OPFS), which is a private storage area for the extension's origin. Nothing is uploaded to any server, and the extension performs no network requests to any external service.

The extension's manifest declares no host permissions and makes no fetch, XMLHttpRequest, or WebSocket calls. This is enforceable from source: the repository at github.com/igorsaevets/ironmemo-recorder is public and auditable.

3. Retention and deletion

Recordings remain in local storage until the user deletes them. Deletion is available from the "Записи" (Recordings) page in the extension: each recording has a "Удалить сессию" (Delete session) button. Uninstalling the extension deletes all recordings and all settings.

There is no server-side copy to retain or delete, because nothing is uploaded.

4. Sharing

The extension does not sell, transfer, or share any user data. There is no third-party service, no analytics provider, no advertising network, and no crash-reporting service. There is no way for the extension author or anyone else to access recordings on the user's device.

5. AI and model training

The extension does not use recordings for artificial-intelligence processing, training, transcription, summarization, or any related purpose. If a future version of the extension adds an AI feature, that feature will be opt-in and disclosed in the extension's consent screen before it is activated. The current version has no such feature.

6. Recording consent and user responsibility

The extension shows a consent screen on first use that summarizes what it does and what it does not do. By starting a recording, the user confirms that they have the right to record all participants in the meeting under the law of their jurisdiction. Recording laws differ substantially between countries and, within the United States, between states — the user is responsible for compliance with the law that applies to them.

7. Permissions used, and why

  • tabCapture — required to record audio from the tab the user selects.
  • offscreen — required by Manifest V3 to hold the recording pipeline while the popup is closed.
  • storage — required to save recording settings and consent state in chrome.storage.local.
  • unlimitedStorage — required so long recordings are not truncated by Chrome's default quota (approximately 60 megabytes per hour of Opus 48 kbps audio; a full workday of recording exceeds the default quota).

The extension declares no host permissions and no optional permissions. The full manifest.json is visible in the public repository linked above.

9. Changes to this policy

If the extension's data-handling practices change, this page will be updated and the extension's consent screen will be shown again automatically, so that users must accept the new terms before continuing to record. The consent screen carries a version number that is incremented for exactly this purpose.

This policy is written in plain English on purpose. If any part of it is unclear, please open an issue on the repository and it will be revised.
