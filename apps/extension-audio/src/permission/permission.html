Разрешите доступ к микрофону

IronMemo Recorder записывает звук через встроенное невидимое окно расширения (offscreen document). Chrome не показывает диалог разрешения микрофона напрямую в невидимом окне — поэтому нужна эта видимая страница. Это делается один раз.

После нажатия кнопки Chrome покажет стандартный запрос — разрешите, и запись будет работать во всех сессиях без повторного вопроса.

Готов запросить разрешение.

Что делать, если ошибка вернулась после «Разрешить»:

  1. Откройте chrome://extensions
  2. У IronMemo нажмите Подробнее → Настройки сайта
  3. Раздел Микрофон — переключите на Разрешить
  4. Вернитесь сюда и нажмите «Разрешить микрофон» ещё раз

Chrome иногда «съедает» первый запрос без диалога — известное поведение MV3. Ручное разрешение через настройки сайта — надёжный резерв.
