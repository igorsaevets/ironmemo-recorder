Что Chrome здесь действительно умеет кодировать

Чего эта страница принципиально не может сказать. Браузер не раскрывает, какой физический блок выполняет кодирование. Строк «обнаружен NVENC» или «используется Quick Sync» здесь не будет никогда — не из осторожности, а потому что такого API не существует: раскрытие железа закрыто ради защиты от fingerprinting. Что здесь есть: измеренная скорость кодирования, проверка вывода декодированием, подсказка powerEfficient и разница в ответах на prefer-hardware против prefer-software. Последняя — единственный честный косвенный признак того, что два разных пути кодирования вообще существуют. Точный ответ про NVENC / Quick Sync / AMF / VideoToolbox возможен только в нативном desktop-приложении.

Сессии записи в OPFS

Файлы лежат в Origin Private File System расширения. Отсюда их можно скачать и проверить декодированием ЦЕЛИКОМ через WebCodecs AudioDecoder — с подсчётом сэмплов, а не по полю duration. Именно это, а не «файл открывается», считается проверкой.
